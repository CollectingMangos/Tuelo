# Tuelo - E-Commerce Platform

A modern, scalable e-commerce platform built with PHP, featuring a responsive user interface and robust backend architecture.

## Overview

Tuelo is a full-featured e-commerce solution designed to provide a seamless shopping experience for customers and comprehensive management tools for store operators. The platform combines PHP backend processing with responsive frontend technologies to deliver a reliable and user-friendly marketplace.

## Tech Stack

- **Backend**: PHP (84%)
- **Frontend**: CSS (14.8%), JavaScript (1.1%)
- **Other**: Hack (0.1%)

## Features

- 🛍️ Product catalog management
- 🛒 Shopping cart functionality
- 💳 Secure payment processing
- 👤 User account management
- 📊 Order tracking and history
- 🎨 Responsive design
- 🔒 Secure authentication

## Getting Started

### Prerequisites

- PHP 7.4 or higher
- Web server (Apache/Nginx)
- MySQL/MariaDB database
- Composer (for dependency management)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/CollectingMangos/Tuelo.git
   cd Tuelo
   ```

2. **Install dependencies**
   ```bash
   composer install
   ```

3. **Configure your environment**
   - Copy `.env.example` to `.env`
   - Update database credentials and other configuration values

4. **Set up the database**
   ```bash
   php artisan migrate
   ```

5. **Start the application**
   - For development: Use a local PHP server or configure Apache/Nginx
